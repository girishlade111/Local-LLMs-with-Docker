Run LLMs Locally with Docker

Unlock the power of Large Language Models on your own machine. This guide provides an interactive walkthrough for setting up and running open-source AI models using Docker, ensuring privacy, speed, and full control.

Why Run an LLM Locally?

Moving beyond cloud-based services offers significant advantages. Explore the key benefits of having a powerful AI right on your desktop.

🔒

Total Privacy

Your data and prompts never leave your machine. Perfect for sensitive information and confidential work.

💰

No Subscriptions

Avoid recurring fees and API costs. Run models as much as you want after the initial setup.

🔌

Offline Access

Your AI assistant works without an internet connection, ensuring constant availability.

🛠️

Deep Customization

Fine-tune models with your own data and experiment with different configurations and parameters freely.

The 4-Step Setup Guide

We'll use Ollama, a fantastic tool that simplifies running LLMs. It packages everything you need into a single Docker container.

1

Install Docker

If you don't have it already, download and install Docker Desktop for your operating system. It provides the containerization engine needed to run Ollama.

Get Docker Desktop →
2

Run the Ollama Container

Open your terminal and run this command. It will download the Ollama image and start it. For GPU support (NVIDIA), use the second command.

For CPU:

docker run -d -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama

For NVIDIA GPU:

docker run -d --gpus=all -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama
3

Pull a Model

Now, "exec" into the running container to download a model. We'll use Llama 3 (8B) as an example. This command tells Ollama to download the model files.

docker exec -it ollama ollama run llama3
4

Chat with Your LLM!

That's it! After pulling the model, you'll be dropped into a chat prompt in your terminal. You can also interact with it via an API endpoint, perfect for building applications.

API Example (using curl):

curl http://localhost:11434/api/generate -d '{ "model": "llama3", "prompt": "Why is the sky blue?" }'
